# Contributing

Thanks for helping with Seicento 900 Cup. Please read the
[Code of Conduct](CODE_OF_CONDUCT.md) first.

## Getting started

The active game is the Godot 4 project in [`godot/`](godot/):

```sh
godot --path godot
```

The browser game at the repository root is only a reference for porting and parity work. Make new
gameplay, UI and rendering changes in the Godot project. Outstanding work is tracked in
[`TASKS.md`](TASKS.md) and [`godot/README.md`](godot/README.md).

## Generated assets

3D models, track data, the Brzeszcze map and sounds are generated by scripts under
[`tools/`](tools/). Change the script and rebuild rather than editing a `.glb`, `.json` or `.wav` by
hand. [`AGENTS.md`](AGENTS.md) describes each generator and the names the game code relies on.

## Tests

Run the headless suite before opening a pull request:

```sh
godot --headless --path godot -s tests/run_tests.gd
```

Scripts starting with `_` in `godot/tests/` are probes that need a window; they aren't part of the suite.

## Pull requests

- Branch from `main` and keep each pull request to one change.
- Say what changed and why, and how you checked it. Add screenshots for visual changes.
- Add or update tests when behaviour changes.
- Don't commit unrelated generated files.

## Reporting bugs and ideas

Use the [issue templates](https://github.com/martwyymem/seicento900/issues/new/choose). For security
problems, see [SECURITY.md](SECURITY.md).
