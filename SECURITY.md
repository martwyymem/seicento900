# Security Policy

## Supported versions

Only the latest [release](https://github.com/martwyymem/seicento900/releases/latest)
and the `main` branch receive fixes.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately
through GitHub: **Security → Report a vulnerability** on this repository
(<https://github.com/martwyymem/seicento900/security/advisories/new>).

Include what you found, how to reproduce it, and the version or commit. You can
expect a first reply within a few days. Once a fix is released the report may be
disclosed publicly, with credit to you if you want it.

This is an offline single-player game, so the most relevant issues are things
like unsafe handling of save files or downloaded content, and problems in the
build and release tooling.
