# Optional art assets: skies, ground textures and trees

The race world looks fine without any downloads: the sky, clouds, stars, asphalt, grass, gravel, trees,
harbour water and Monaco facades are all generated by shaders in [`shaders/`](shaders/). When the
files below are present, the game uses them instead (or on top). It never requires them, and deleting
them brings back the procedural look.

Everything recommended here is free. The automatic download uses only CC0 assets (public domain, no
attribution needed).

## Quick start

```sh
python3 tools/fetch_assets.py            # ~64 MB: 13 HDRI skies (2K) + 4 ground materials (1K)
python3 tools/fetch_assets.py --set minimal   # ~25 MB: 4 skies + asphalt and grass
python3 tools/fetch_assets.py --list     # show what it would download
python3 tools/fetch_assets.py --help     # resolutions, destination, skies/textures only
```

Run it from the repository root, then start the game (`godot --path godot`). The script reads exact
URLs and MD5 sums from the [Poly Haven API](https://api.polyhaven.com), verifies every file and skips
files that are already present. The downloaded folders are listed in `godot/.gitignore`, so they are
not committed. Anyone can fetch them again with the same command.

## Where files go

The loader ([`scripts/ui/world_assets.gd`](scripts/ui/world_assets.gd)) looks in two roots:

| Root | Use |
|---|---|
| `godot/assets/` (`res://assets`) | While developing, or to ship the assets inside an exported build |
| `user://assets` | Adding assets to an already-exported game. On macOS this is `~/Library/Application Support/Godot/app_userdata/Seicento 900 Cup/assets`. Use `--dest` with the fetch script. |

```
assets/
  sky/                 *.hdr (also .exr/.png/.jpg): equirectangular panoramas
  textures/
	asphalt/           track surface (also used for asphalt run-off)
	pit_lane/          pit lane (falls back to asphalt/)
	grass/             terrain and grass run-off
	gravel/            gravel traps
  models/
	trees/             *.glb / *.gltf tree models
```

Raw files work straight away, because the game decodes them at runtime. When the Godot editor is
open it imports them as well. Both paths work.

## Skies (HDRI)

Default set: the Poly Haven **Qwantani pure-sky time-lapse**. It shows one location photographed from
dawn to night, so blending neighbouring times of day stays seamless. "Pure sky" versions have no ground
or buildings, so nothing floats above the circuit.

| File (Poly Haven id) | Used for |
|---|---|
| [qwantani_dawn_puresky](https://polyhaven.com/a/qwantani_dawn_puresky) | before sunrise |
| [qwantani_sunrise_puresky](https://polyhaven.com/a/qwantani_sunrise_puresky) | sunrise |
| [qwantani_morning_puresky](https://polyhaven.com/a/qwantani_morning_puresky) | morning |
| [qwantani_mid_morning_puresky](https://polyhaven.com/a/qwantani_mid_morning_puresky) | late morning |
| [qwantani_noon_puresky](https://polyhaven.com/a/qwantani_noon_puresky) | midday |
| [qwantani_afternoon_puresky](https://polyhaven.com/a/qwantani_afternoon_puresky) | afternoon |
| [qwantani_late_afternoon_puresky](https://polyhaven.com/a/qwantani_late_afternoon_puresky) | late afternoon |
| [qwantani_sunset_puresky](https://polyhaven.com/a/qwantani_sunset_puresky) | sunset |
| [qwantani_dusk_1_puresky](https://polyhaven.com/a/qwantani_dusk_1_puresky), [dusk_2](https://polyhaven.com/a/qwantani_dusk_2_puresky) | twilight |
| [qwantani_night_puresky](https://polyhaven.com/a/qwantani_night_puresky), [moonrise](https://polyhaven.com/a/qwantani_moonrise_puresky) | night |
| [kloofendal_overcast_puresky](https://polyhaven.com/a/kloofendal_overcast_puresky) | rain / overcast |

How the game uses them:

- On first run each sky is analysed once. The brightest pixel gives the sun position, and a clipped
  average gives the overall brightness. The results are cached in `user://sky_cache.cfg`.
- As the race clock runs, the two skies whose sun elevation brackets the real sun are cross-faded. The
  file name decides morning versus afternoon.
- Each panorama is turned so its sun sits exactly where the game's sun and shadows are.
- Brightness is matched to the game's own day/night palette, so any HDRI "just fits".
- Wet weather fades to the overcast sky. After dark the night sky takes over, or the procedural starry
  sky if there is no night HDRI.
- The drifting procedural clouds are drawn over the photo sky, because the Qwantani set is almost
  cloudless.
- Only two to three panoramas are in video memory at once (about 8 MB each at 2K). Later ones load on a
  worker thread, so changing sky never stalls a race.

Using other HDRIs: any equirectangular `.hdr` works. The file name steers the classification:

| Name contains | Treated as |
|---|---|
| `dawn`, `sunrise`, `morning` | morning sky |
| `afternoon`, `sunset`, `dusk`, `evening` | afternoon/evening sky |
| `night`, `moon` | night sky |
| `overcast` (or no visible sun and no time hint) | rain/overcast sky |

Otherwise the detected sun elevation is used and the sky serves both halves of the day. Good sources:
[Poly Haven skies](https://polyhaven.com/hdris/skies) (CC0; prefer the `*_puresky` ones) and
[ambientCG HDRIs](https://ambientcg.com/list?type=hdri) (CC0). A 2K resolution is plenty. At 4K
(16–21 MB per file) the sky is only slightly sharper and uses four times the memory.

## Ground textures (PBR)

Each folder needs a colour map. A normal map (OpenGL convention) and a roughness map are optional. Maps
are recognised by name: `_diff` / `_color` / `albedo` / `basecolor`, `nor_gl` / `normalgl`, and
`_rough` / `roughness`. DirectX normal maps (`nor_dx`, `NormalDX`) are ignored because their green
channel is flipped.

The photo supplies the detail, while the circuit's own colours are kept: the texture is divided by its
average colour and multiplied by the track palette. Tiling is hidden by a second, rotated sample and
large-scale noise. Rubber on the racing line, dusty edges, repair patches, puddles and rain ripples are
still added by the shader.

| Folder | Default (Poly Haven, CC0) | Alternatives (ambientCG, CC0) |
|---|---|---|
| `asphalt/` | [asphalt_track](https://polyhaven.com/a/asphalt_track) | [Asphalt031](https://ambientcg.com/a/Asphalt031), [Road007](https://ambientcg.com/a/Road007) |
| `pit_lane/` | [asphalt_pit_lane](https://polyhaven.com/a/asphalt_pit_lane) | [clean_asphalt](https://polyhaven.com/a/clean_asphalt) |
| `grass/` | [sparse_grass](https://polyhaven.com/a/sparse_grass) | [leafy_grass](https://polyhaven.com/a/leafy_grass), [Grass004](https://ambientcg.com/a/Grass004), [Grass001](https://ambientcg.com/a/Grass001) |
| `gravel/` | [gravelly_sand](https://polyhaven.com/a/gravelly_sand) | [Gravel023](https://ambientcg.com/a/Gravel023), [Gravel022](https://ambientcg.com/a/Gravel022) |

With ambientCG, download the `1K-JPG` zip and put `*_Color.jpg`, `*_NormalGL.jpg` and
`*_Roughness.jpg` in the folder. The file names already match. Use one material per folder, and 1K is
enough because the shader tiles it every 3–4 m.

## Trees

Without models the game builds low-poly spruces and broadleaf trees that sway in the wind. To use real
models, put `.glb` or `.gltf` files in `assets/models/trees/`:

- One tree per file, or one file holding several trees side by side as separate root nodes. Each root
  becomes its own variant.
- Models are rescaled to 8–15 m tall, stood on the ground and given a random turn. Their own materials
  are kept.
- Keep them low-poly (under about 3,000 triangles per tree). Hundreds are drawn per circuit. Photo-scanned
  trees with millions of polygons (such as Poly Haven's) are far too heavy.

| Pack | Licence | Notes |
|---|---|---|
| [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) | CC0 | Many trees in GLB, matching the game's low-poly style |
| [Quaternius Ultimate Nature](https://quaternius.com/packs/ultimatenature.html) | CC0 | Pines, birches and oaks; export the trees you want to GLB |
| [Poly Pizza](https://poly.pizza) | mostly CC0 / CC-BY | Search "tree"; check each model's licence |
| [Low poly trees (Polybuild)](https://store.godotengine.org/asset/polybuild/low-poly-trees/) | MIT | Godot Asset Store |
| [EZ-Tree Godot port](https://store.godotengine.org/asset/leomclaughlin4/ez-tree-godot-port/) | see page | Procedural tree generator. Bake trees and save them as GLB. |

## Graphics quality

`race_world.gd` has four presets. The options page does not offer them yet, so set the preset in
`user://graphics.cfg` (the game keeps the key when it saves its own settings):

```ini
[graphics]
quality=2   ; 0 Low, 1 Medium, 2 High (default), 3 Ultra
```

| | Low | Medium | High | Ultra |
|---|---|---|---|---|
| MSAA | off | off | 2× | 4× |
| Sun shadows | 2 splits, 220 m | 4 splits, 320 m | 4 splits, 420 m | 4 splits, 560 m, soft penumbra |
| Screen-space indirect light | off | off | on | on |
| Volumetric fog (rain, night beams) | off | off | on | on |
| Trees | 45 % | 75 % | 100 % | 150 % |
| Texture filtering | 2× | 4× | 8× | 16× aniso |

The SSAO, shadows and wet-road reflections (SSR) switches on the options page still apply on top.
Reflections off is the default. Turning them on makes puddles mirror the cars and buildings.
