# Agent instructions

> ⚠️ **MANDATORY INSTRUCTION FOR ALL AI AGENTS & MODELS**:
> Every agent and model **MUST read [`TASKS.md`](TASKS.md) before planning or running any tasks**. `TASKS.md` is the authoritative bible and roadmap for all new game features (dynamic weathers, retro shaders, Polish & Tokyo city tracks, campaign mode, and streamlined menus). Always consult and align with `TASKS.md` before writing or modifying code.

## Current game

The active game is the Godot project in [`godot/`](godot/). Open it with
`godot --path godot` or open [`godot/project.godot`](godot/project.godot) in the Godot editor.
Make new gameplay, UI, and rendering changes in this Godot project.

The former browser game at the repository root is a temporary reference for porting and parity work.
Consult it when checking behavior, but do not treat it as the active version. Keep it until the
Godot port is complete; the outstanding work is tracked in [`godot/README.md`](godot/README.md).

Track data is shared/generated from the repository's `tools/` sources. Godot parity tests and
reference data live under `godot/tests/`.

## 3D models (Blender)

Blender is installed at `/Applications/Blender.app/Contents/MacOS/Blender` and runs headless. Models are
generated by Python scripts under [`tools/blender/`](tools/blender/), so change the script and rebuild
rather than editing a GLB by hand. The car is
[`tools/blender/build_seicento.py`](tools/blender/build_seicento.py), which writes
`godot/models/seicento.glb`:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/build_seicento.py -- --renders /tmp/seicento
```

`--renders DIR` saves preview PNGs (front, rear, side, top and three-quarter views). Look at them before
opening Godot. `--blend FILE` also saves the .blend. `race_car_visual.gd` finds the meshes by object name
(`Body`, `Details`, `Stripes`, `Wheel`) and the per-car surfaces by material name (`Paint`, `Taillight`,
`Glass`, `Headlight`), so keep those names stable.

The trackside structures come from [`tools/blender/build_trackside.py`](tools/blender/build_trackside.py), which writes
`godot/models/trackside.glb`. It builds modular pieces: grandstand bays, tiers, crowd and sponsor boards, pit
garages and race control, the start gantry, and TV towers. `race_world.gd` lays them out along each circuit.
Shared mesh helpers are in [`tools/blender/kit.py`](tools/blender/kit.py). Keep the object names and the layout
constants (`STAND_*`, `PIT_*`, `GANTRY_BEAM_Y` in `race_world.gd`) in step with the script. The seated crowd is
coloured by `shaders/crowd.gdshader` from codes in its vertex colours, so it looks green and orange in Blender.

Other Blender scripts follow the same pattern: `build_trees.py` (`trees.glb`, the species the surroundings plant),
`build_furniture.py` (`furniture.glb`, marshal posts, braking boards, hoardings, bridges, paddock, tyre walls) and
`build_landmarks.py` (`landmarks.glb`: Indianapolis Pagoda and scoring pylon, Suzuka Ferris wheel, Le Mans tyre
bridge, Monza podium, Nürburg castle, Casino de Monte-Carlo, Silverstone Wing, harbour yachts). The surroundings
(`tools/fetch_surroundings.py` then `tools/build_surroundings.py`) come from OpenStreetMap and are baked to
`godot/data/tracks/<key>_env.json`; add a landmark by naming its OSM element in `LANDMARKS` in
`build_surroundings.py` and its nominal footprint in `LANDMARK_SIZE` in `surroundings.gd`.

## Sounds

The player's engine is synthesised live (`godot/scripts/ui/race_audio.gd`). Every other sound (other cars,
kerbs, gravel, rain, crowd, impacts, pit crews) is baked by [`tools/build_sounds.py`](tools/build_sounds.py)
(numpy) into `godot/audio/*.wav`, so change the script and rebuild (`python3 tools/build_sounds.py --stats`)
rather than editing a WAV, then let Godot reimport (`godot --headless --path godot --import`).
`world_audio.gd` plays them. Its `ENGINE_RPM` and `KERB_RATE` must match the script's.

## Campaign open world (Brzeszcze)

The campaign's free-roam map lives in [`godot/scripts/world/`](godot/scripts/world/) (`open_world.gd` is the mode; game.gd
calls `_enter_open_world`). Its data is baked from OpenStreetMap and EU-DEM by
[`tools/build_open_world.py`](tools/build_open_world.py) into `godot/data/world/brzeszcze*.{json,png}`, so change the
script and rebuild rather than editing the JSON. Its props are `godot/models/town.glb` from
[`tools/blender/build_town.py`](tools/blender/build_town.py). `town_builder.gd` finds them by object name (`Headframe`,
`ChurchSpire`, `Streetlamp`, `TrafficLight`, `BusShelter`, `LevelCrossing`, `FestivalStage`, `FestivalArch`, `Tent`,
`FlagPole`, `CarHatch`, `CarSedan`, `CarVan`, `Maluch`) and the tintable surfaces by material name (`Paint`, `Lamp`,
`Banner`), so keep those names stable. The stage beacons map campaign tracks to the baker's named spots
(`OpenWorld.STAGE_SPOTS`).
