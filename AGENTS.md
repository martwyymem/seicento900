# Agent instructions

## Current game

The active game is the Godot project in [`godot/`](godot/). Open it with
`godot --path godot` or open [`godot/project.godot`](godot/project.godot) in the Godot editor.
Make new gameplay, UI, and rendering changes in this Godot project.

The former browser game at the repository root is a temporary reference for porting and parity work.
Consult it when checking behavior, but do not treat it as the active version. Keep it until the
Godot port is complete; the outstanding work is tracked in [`godot/README.md`](godot/README.md).

Track data is shared/generated from the repository's `tools/` sources. Godot parity tests and
reference data live under `godot/tests/`.

## 3D models (Blender)

Blender is installed at `/Applications/Blender.app/Contents/MacOS/Blender` and runs headless. Models are
generated by Python scripts under [`tools/blender/`](tools/blender/), so change the script and rebuild
rather than editing a GLB by hand. The car is
[`tools/blender/build_seicento.py`](tools/blender/build_seicento.py), which writes
`godot/models/seicento.glb`:

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b -P tools/blender/build_seicento.py -- --renders /tmp/seicento
```

`--renders DIR` saves preview PNGs (front, rear, side, top and three-quarter views). Look at them before
opening Godot. `--blend FILE` also saves the .blend. `race_car_visual.gd` finds the meshes by object name
(`Body`, `Details`, `Stripes`, `Wheel`) and the per-car surfaces by material name (`Paint`, `Taillight`,
`Glass`, `Headlight`), so keep those names stable.
