# Seicento 900 Cup

The current game is the Godot project in [`godot/`](godot/). Open it with Godot 4.7 by running:

```sh
godot --path godot
```

To change the game, start with [`how2.md`](how2.md): it lists where the important settings live (car, tyres,
circuits, AI difficulty, pit crews, race control, graphics, key bindings, save files).

For project layout, controls, port status, and development notes, see [`godot/README.md`](godot/README.md).
Repository-wide agent instructions are in [`AGENTS.md`](AGENTS.md).

The previous browser implementation is temporarily retained as a behavioral reference while the
Godot port is completed. See the remaining port work in the Godot README before removing it.
